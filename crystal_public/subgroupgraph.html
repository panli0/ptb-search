Bilbao Crystallographic Server SUBGROUPGRAPH Help

Group-Subgroup Graph and Chains of Maximal Subgroups

Graph and chains ...

For a given group and supergroup the program SUBGROUPGRAPH will give the graph of maximal subgroups that relates these two groups and, in the case that the index is specified, all of the possible chains of maximal subgroup that relate the two groups. In the latter case, also there is a possibility to obtain all of the different subgroups of the same type.

As an input data you should give (or select) the numbers of the group and the subgroup, and the index.

A tutorial on the application of several tools of this server including SUBGROUPGRAPH in the study of group-subgroup phase transitions can be found here.
