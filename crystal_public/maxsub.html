Maximal Subgroups of Space Groups


List with the maximal subgroups
For each one of the space group you can obtain the list with its maximal subgroups. This list contains the numbers and the symbols of these subgroups as well as the corresponding index and the transformation matrix that relates the basis of the group with that of the subgroup.

If you are using this program in the preparation of a paper, please cite it in the following form:

Aroyo, et. al. Zeitschrift fuer Kristallographie (2006), 221, 1, 15-27.
